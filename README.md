## 📌 Project Title
**Sales Data Analysis and Business Insights**

## 🏢 Internship Details
- **Company:** Nanoglint Technologies
- **Role:** Data Analyst Intern
- **Duration:** 18 June 2026 – 18 August 2026
- **Domain:** Data Analysis

## 📖 About the Project
This project was completed as part of my summer internship at Nanoglint Technologies. The project focuses on analyzing sales data to understand business performance and identify meaningful insights.

The analysis includes data cleaning, sales and profit analysis, product performance, regional performance, monthly sales trends, and category profitability.

## 🎯 Objectives
- Analyze and clean the sales dataset
- Calculate total sales and profit
- Identify top-performing products
- Compare sales across different regions
- Analyze monthly sales trends
- Understand category-wise profitability
- Create visualizations to present the findings

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
