# Summer Internship 2026 — Sales Data Analysis

## Project Overview
A data analysis project that studies sales, profit, products, regions, and monthly trends using a realistic sales dataset.

## Internship Details
- Organization: Nanoglint Technologies
- Duration: 18 June 2026 – 18 August 2026
- Project Area: Data Analysis

## Objectives
- Clean and validate sales data
- Calculate sales, profit, units sold, and profit margin
- Identify top-performing products
- Compare regional performance
- Analyze monthly sales trends
- Compare category profitability

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## Project Structure
```text
data/sales_data.csv
notebooks/Sales_Analysis.ipynb
visualizations/
README.md
requirements.txt
```

## Results

## How to Run
1. Install Python.
2. Install dependencies with `pip install -r requirements.txt`.
3. Open `notebooks/Sales_Analysis.ipynb` in Jupyter Notebook.
4. Run the cells from top to bottom.
